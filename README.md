## 🌟 Project Overview

This project implements a **cloud-native voting application** that allows users to vote for their favorite pet (Cats 🐱 vs Dogs 🐶) and see real-time results. It's designed to demonstrate **production-ready Kubernetes patterns** and **microservices architecture** with multiple interconnected components.

The application showcases:
- ✅ **Multi-container orchestration** with Kubernetes
- ✅ **Inter-service communication** within a cluster
- ✅ **Stateful applications** (PostgreSQL) in containers
- ✅ **Caching layer** with Redis for performance
- ✅ **Background processing** with worker microservice
- ✅ **NodePort exposure** for external access
